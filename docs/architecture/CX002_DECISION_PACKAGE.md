## Recommendation in one sentence

Make the public showcase sample-first, transient, and explicitly simulated; evaluate a static Vite deployment on Vercel Hobby if the owner confirms personal, non-commercial eligibility; keep trusted real-model inference local and defer Supabase until a persistent radiologist workflow is approved.

## Provider fit checked on 2026-10-27

Vercel's current Vite guide describes SPA deep-link rewrites, and its Hobby documentation lists a free tier restricted to personal, non-commercial use. This is a plausible frontend host, subject to the owner's account and terms. [Vite guide](https://vercel.com/docs/frameworks/frontend/vite), [Hobby plan](https://vercel.com/docs/plans/hobby).

Supabase's Free plan currently lists $0/month, 500 MB database and 1 GB file storage; projects with low activity can pause over a seven-day period. Those capacities do not create a need for Auth, Postgres or Storage in a no-persistence showcase. Edge Functions use a Deno-compatible runtime and hosted limits of 256 MB memory and 2 seconds CPU per request, which do not suit direct replacement of the Python/PyTorch inference process. [Pricing](https://supabase.com/pricing), [pausing](https://supabase.com/docs/guides/platform/free-project-pausing), [runtime](https://supabase.com/docs/guides/functions), [limits](https://supabase.com/docs/guides/functions/limits).

No cost forecast is possible without chosen hosting, expected traffic, image sizes, or a decision on a backend. No provider has been selected or deployed here.
